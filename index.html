Computer-aided statistical analysis

BSc — University of Bonn

This is the course script for Computer-aided statistical analysis.

The course introduces essential ideas of modern applied and computational statistics, with particular emphasis on simulation experiments, regression modeling, model assessment, model selection, resampling, and cross-validation.

We will mostly study linear and generalized linear regression models, many of which you may already have encountered in earlier statistics courses. The distinguishing feature of this course is that computation is used systematically to investigate how statistical methods work, when approximations are accurate, how procedures behave in finite samples, and where their limitations become visible.

Throughout the course, we use Python and R as computational tools. In the lecture, examples will mostly be coded in Python.

The focus of this course is not on coding (So the Statistic part is much more important than the Computer part of the lecture). However, to follow the course, it is required, that you can at least understand an interpret the provided code.

Computational work

Computation is used throughout the course to complement statistical theory.

We will use Python to:

  • work with data in reproducible notebooks and scripts;

  • generate random variables and simulated data sets;

  • visualize probability distributions and sampling distributions;

  • investigate the law of large numbers and the central limit theorem;

  • study finite-sample and asymptotic distributions of estimators;

  • design and run reproducible Monte Carlo experiments;

  • estimate bias, variance, RMSE, coverage, and Monte Carlo uncertainty;

  • fit linear and generalized linear regression models;

  • investigate residuals, leverage, influence, heteroskedasticity, and model misspecification;

  • compare candidate models;

  • estimate predictive performance using validation and cross-validation;

  • use bootstrap methods for uncertainty assessment;

  • fit and tune regularized models;

  • investigate flexible regression models;

  • visualize fitted models, diagnostics, resampling results, and simulation results.

Programming is therefore not a separate but also not the main subject of the course. It is a tool for understanding, testing, and applying statistical methods.

A recurring question throughout the course will be:

What does the theory predict, what happens in a finite sample, and what can we learn by simulating it?

If you have never coded or used Python before, please find our Python Tutorial to help you getting started.

Use of LLMs

You are welcome to use an LLM, such as ChatGPT, Claude, Le Chat, or a similar tool, to support your learning.

Used carefully, these tools can help explain mathematical notation, provide alternative explanations or generate additional examples. Most importantly, it can help to effortlessly translate and test statistical ideas into Python (or R, if you prefer).

A useful rule is:

You may use an LLM to help you learn, but you should be able to explain every statistical argument and every line of code that you use.

In a more general context, good uses of an LLM include asking it to:

  • explain a statistical concept in simpler language;

  • provide intuition for a definition or result;

  • give another example similar to one from class;

  • explain a step in a derivation after you have attempted it yourself;

  • help interpret an error message in Python or R;

  • suggest checks for a simulation study or statistical workflow;

  • generate additional practice questions;

  • compare two statistical approaches;

  • act as a coding assistant when you understand and verify the resulting code.

Poor uses include asking an LLM to:

  • solve exercises before you have attempted them yourself;

  • produce derivations that you cannot explain;

  • write code that you cannot read or justify;

  • choose a statistical method without checking its assumptions;

  • generate output that you submit without verifying it;

  • replace statistical reasoning with a long piece of automatically generated code.

How to work with the course material

Computer-aided statistics is best learned by combining statistical reasoning with computation.

For each topic, you should:

  1. read the lecture notes and identify the main statistical question, definitions, and results;

  2. solve the coding lab exercises at the end of a chapter;

  3. solve the exercises within each lecture;

  4. try out and manipulate the code in the given in the lecture notes (vary assumptions, sample sizes, parameters, and random seeds and investigate what changes);

Exam information

The exam will be a written exam lasting 60 minutes.

You are allowed to bring:

  • a one-page hand-written A4 one-sided cheat sheet.

The cheat sheet should support your memory rather than replace your understanding. It is best used for important definitions, key formulas, properties of estimators, diagnostic quantities, resampling procedures, and results that are useful when analyzing statistical models. That the Cheat-Sheet is hand-written is mandatory (in order that some bring LLM-generated Cheatsheets without putting effort in crafting and organizing it)!
