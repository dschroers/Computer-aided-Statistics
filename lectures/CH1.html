1 Random variables and distributions

1.1 Sample spaces, outcomes, and events

A random experiment has a sample space \(\Omega\), the set of possible outcomes. An event \(A\) is a subset of \(\Omega\) to which we can assign a probability.

  • A single coin toss: \(\Omega=\{H,T\}\), with event \(A=\{H\}\).
  • The number of tosses until the first heads: \(\Omega=\{1,2,3,\ldots\}\).
  • Systolic blood pressure (continuous): We measure systolic blood pressure in mmHg, so \(\Omega=(0,\infty).\) An example of an event is (A=[140,)), indicating elevated blood pressure.

We describe probabilities by a probability distribution or measure \(\mathbb P\). A probability distribution is a function \(\mathbb P\) that assigns a number \(\mathbb P[A]\) in \([0,1]\) to an event \(A\subset \Omega\), and satisfies two conditions:

  • (normalization) \(\mathbb P[\Omega]=1\)
  • (countable additivity) for a (possibly infinite) number of events \(A_1,A_2,\ldots\), which are mutually disjoint, i.e. \(A_i\cap A_j = \emptyset\) when \(i\neq j\) it is \[ \mathbb P\left(\bigcup_{i=1}^{\infty}A_i\right) =\sum_{i=1}^{\infty}\mathbb P(A_i). \]
Warning

Strictly, probabilities are defined on a suitable collection of events (a \(\sigma\)-algebra), not necessarily on every subset of an uncountable sample space. We will usually leave the \(\sigma\)-algebra implicit.

Some useful consequences are summarized below: \[ \begin{aligned} \mathbb P(\varnothing)&=0,\\ \mathbb P(A^c)&=1-\mathbb P(A),\\ A\subseteq B&\implies \mathbb P(A)\leq\mathbb P(B),\\ \mathbb P(A\cup B)&=\mathbb P(A)+\mathbb P(B)-\mathbb P(A\cap B). \end{aligned} \] Proof: On the blackboard

For \(\mathbb P(B)>0\), the conditional probability of \(A\) given \(B\) is

\[ \mathbb P(A\mid B)=\frac{\mathbb P(A\cap B)}{\mathbb P(B)}. \]

Events \(A\) and \(B\) are independent if \(\mathbb P(A\cap B)=\mathbb P(A)\mathbb P(B)\). Independence is not the same as being mutually exclusive.

ImportantFrequentist interpretation

In repeated independent trials with the same event probability \(p=\mathbb P(A)\), the observed fraction of trials in which \(A\) occurs tends toward \(p\) as the number of trials increases. This is a consequence of the law of large numbers, not an additional probability axiom.

1.3 Random variables

A (real-valued) random variable is a (measurable) function \(X:\Omega\to\mathbb R\). It assigns a number to each outcome of an experiment. Its distribution tells us which values it takes and with what probabilities. For example, if \(X\) indicates whether a coin toss gives heads, then \(X=1\) for heads and \(X=0\) for tails.

The distinction is important: \(X\) is a random variable, \(x\) is a possible value, and \(X(\omega)\) is its realized value for a particular outcome \(\omega\).

In practice, we often do not know—or care about—the full sample space \(\Omega\). It may represent all possible states of the world, including many details that we cannot observe. A random variable allows us to focus on one particular feature of this complexity.

For example, the outcome of a coin toss depends on many physical factors: the force of the flip, the angle, air resistance, and so on. Rather than modeling all these details, we define \(X=1\) if the coin lands heads and \(X=0\) otherwise. Assuming a fair coin, we simply write \[ \mathbb P[X=1]=\mathbb P[\{\omega \in \Omega: X(\omega)=0\}]=\frac12. \]

More generally, the distribution of \(X\) describes the probabilities of the values we actually observe, without requiring us to model everything that produces them: \[ \mathbb P(X\in A)=\mathbb P(\{\omega\in\Omega:X(\omega)\in A\}). \]

1.4 PMFs, densities, and distribution functions

The cumulative distribution function (CDF) of any real-valued random variable \(X\) is

\[ F_X(x)=\mathbb P(X\leq x),\qquad x\in\mathbb R. \]

It is - nondecreasing, - right-continuous, and - tends to \(0\) and \(1\) at the two ends of the real line. Every real-valued random variable has a CDF.

For a discrete random variable, its probability mass function (PMF) is \(p_X(x)=\mathbb P(X=x)\), and the masses sum to one. For a continuous random variable with density \(f_X\),

\[ \mathbb P(a<X\leq b)=\int_a^b f_X(x)\,dx, \qquad F_X(x)=\int_{-\infty}^x f_X(t)\,dt. \]

A density is not itself a probability: it may exceed one, while probabilities are given by areas under the density. For a continuous random variable, \(\mathbb P(X=x)=0\) for each individual \(x\).

Joint distributions and independence. Two random variables \(X,Y\) have a joint distribution. Their marginal distributions concern \(X\) and \(Y\) separately. They are independent if, for all \(x,y\),

\[ \mathbb P(X\leq x,Y\leq y)=F_X(x)F_Y(y). \]

For variables with a joint density this is equivalent to factorization \(f_{X,Y}(x,y)=f_X(x)f_Y(y)\) (almost everywhere). We will use this when discussing random samples.

1.5 Expectation, variance, covariance, and moments

The expected value of \(X\), when it exists, is its probability-weighted average:

\[ \mathbb E[X]=\begin{cases} \sum_x x\,p_X(x),&X\text{ discrete},\\[3pt] \int_{-\infty}^{\infty}x f_X(x)\,dx,&X\text{ with density}. \end{cases} \]

More generally, \(\mathbb E[g(X)]\) is obtained by replacing \(x\) with \(g(x)\) in the same sum or integral. Linearity gives \[ \mathbb E[aX+bY]=a\mathbb E[X]+b\mathbb E[Y] \] without requiring independence.

Writing \(\mu=\mathbb E[X]\), the variance and standard deviation are \[ \operatorname{Var}(X)=\mathbb E[(X-\mu)^2] =\mathbb E[X^2]-\mu^2,\qquad \operatorname{SD}(X)=\sqrt{\operatorname{Var}(X)}. \]

A raw moment is \(\mathbb E[X^k]\); a central moment is \(\mathbb E[(X-\mu)^k]\). The second central moment is the variance. Higher moments can describe aspects of distributional shape, provided they exist.

For two random variables, \[ \operatorname{Cov}(X,Y)=\mathbb E[(X-\mathbb E[X])(Y-\mathbb E[Y])], \] and, when both standard deviations are positive, \(\operatorname{Corr}(X,Y)=\operatorname{Cov}(X,Y)/(\operatorname{SD}(X)\operatorname{SD}(Y))\).

\[ \operatorname{Var}(X+Y)=\operatorname{Var}(X)+\operatorname{Var}(Y) +2\operatorname{Cov}(X,Y). \] When \(\operatorname{Cov}(X,Y)= 0\), this is Bienyamé’s formula. Independence implies zero covariance (when the relevant moments exist); the converse is generally false.

Like probabilities, moments can also be interpreted in a frequentist context: They are the (scaling) limits of sums of independent random experiments. That is, \[\mathbb E[X^m]= \lim_{n\to \infty} \frac 1n\sum_{i=1}^n X_i^m\]$ with probability \(1\) when \(\mathbb E[|X|^m]<\infty\) and \(X_1,...,X_n\) are independent random variables with the same distribution as \(X\). This frequentist interpretation is a direct corollary of the law of large numbers. We will discuss it in the next section

2 Asymptotics of averages of indepenent random variables

The majority of statistical methods relies on asymptotic concepts. Indeed, in most cases, we do not have perfect knowledge about the distribution of our data. Asymptotic concepts help us to find out, if we can identify certain aspects about this latent distribution when we sample more and more data. The most essential asymptotic concepts are the basic Law of large numbers and Central Limit Theorem for averages of independent and identically distributed (i.i.d.) random observations (random variables).

Precisely, a random sample \(X_1,\ldots,X_n\) is usually modeled as i.i.d. observations (random variables) with a common distribution function \(F\). The distribution describes the population or data-generating process; the realized data are \(x_1,\ldots,x_n\).

The average \[ \overline X_n=\frac1n\sum_{i=1}^n X_i. \] of a random sample is also called the empirical mean.

To understand asymptotic concepts in statistics, we need to recall different types of probabilitstic convergence.

2.1 Convergence of random variables

When studying the empirical mean \(\overline X_n\), we want to understand what happens as the sample size \(n\) increases. Unlike a sequence of ordinary numbers, however, \(\overline X_n\) is a random variable for every \(n\): its value depends on the particular sample we draw.

What does it mean for a sequence of random variables \(Y_1,Y_2,\ldots\) to converge to some random variable \(Y\)? There are several answers, depending on what exactly we require to become close. We recall four important notions.

2.1.1 Convergence in probability

We say that \(Y_n\) converges in probability to \(Y\), written

\[ Y_n\xrightarrow{P}Y, \]

if, for every \(\varepsilon>0\),

\[ \mathbb P(|Y_n-Y|>\varepsilon)\longrightarrow 0 \qquad (n\to\infty). \]

Intuition: For a sufficiently large \(n\), it becomes increasingly unlikely that \(Y_n\) differs substantially from \(Y\).

For example, if \(Y_n=\overline X_n\) and \(Y=\mu\) is the population mean, convergence in probability means that the sample average is increasingly likely to be close to the true mean. This is precisely the conclusion of the weak law of large numbers.

Importantly, convergence in probability does not require that every possible sequence of realized values eventually stays close to the limit. Large deviations can still occur, but their probabilities vanish.

2.1.2 Almost sure convergence

We say that \(Y_n\) converges almost surely to \(Y\), written

\[ Y_n\xrightarrow{a.s.}Y, \]

if

\[ \mathbb P\left( \left\{\omega\in\Omega: \lim_{n\to\infty}Y_n(\omega)=Y(\omega) \right\} \right)=1. \]

Intuition: Imagine repeatedly extending the same sequence of observations. Almost sure convergence means that, with probability one, the resulting sequence of values eventually stays arbitrarily close to its limit.

The difference from convergence in probability is subtle but important:

  • In probability: At each large \(n\), the probability of a substantial deviation is small.
  • Almost surely: Along almost every individual infinite sequence of outcomes, substantial deviations eventually stop occurring.

Almost sure convergence is therefore stronger than convergence in probability. The strong law of large numbers establishes this stronger property for sample averages.

2.1.3 Convergence in mean square

We say that \(Y_n\) converges in mean square (or in \(L^2\)) to \(Y\), written

\[ Y_n\xrightarrow{L^2}Y, \]

if

\[ \mathbb E[(Y_n-Y)^2]\longrightarrow 0. \]

Intuition: The expected squared error between \(Y_n\) and \(Y\) vanishes.

For sample averages of i.i.d. observations with mean \(\mu\) and finite variance \(\sigma^2\), we have by Bienaymé’s formula \[ \begin{aligned} \mathbb E[(\overline X_n-\mu)^2] = \operatorname{Var}(\overline X_n) = & \frac{\sum_{i=1}^n \operatorname{Var}( X_i)}{n^2}\\ = & \frac{\sigma^2}{n} \longrightarrow 0. \end{aligned} \]

Thus, the empirical mean converges in mean square to the population mean. This also provides a particularly transparent reason why larger samples tend to produce more precise averages.

Mean-square convergence implies convergence in probability, as follows directly from Markov’s inequality applied to \((Y_n-Y)^2\):

\[ \mathbb P(|Y_n-Y|>\varepsilon) \leq \frac{\mathbb E[(Y_n-Y)^2]}{\varepsilon^2} \longrightarrow 0. \]

2.1.4 Convergence in distribution

Finally, we say that \(Y_n\) converges in distribution to \(Y\), written

\[ Y_n\xrightarrow{d}Y, \]

if their cumulative distribution functions satisfy

\[ F_{Y_n}(t)\longrightarrow F_Y(t) \]

at every point \(t\) where \(F_Y\) is continuous.

Intuition: The probability distribution of \(Y_n\) increasingly resembles the distribution of \(Y\). We do not require the individual values of \(Y_n\) and \(Y\) to be close.

For example, suppose that \(Y_n\) and \(Y\) are independent standard normal random variables for every \(n\). Their distributions are identical, so trivially

\[ Y_n\xrightarrow{d}Y. \]

However, \(Y_n\) does not converge in probability to \(Y\): even for large \(n\), two independently drawn standard normal values can differ substantially.

Convergence in distribution is particularly important for the central limit theorem. The CLT does not say that sample averages themselves converge to a normally distributed random variable. Instead, it says that the distribution of appropriately standardized sample averages approaches a normal distribution.

2.1.5 How are these notions related?

The four convergence concepts form the following hierarchy:

\[ \begin{aligned} Y_n\xrightarrow{a.s.}Y &\implies Y_n\xrightarrow{P}Y,\\[4pt] Y_n\xrightarrow{L^2}Y &\implies Y_n\xrightarrow{P}Y,\\[4pt] Y_n\xrightarrow{P}Y &\implies Y_n\xrightarrow{d}Y. \end{aligned} \]

Almost sure convergence and mean-square convergence do not, in general, imply one another.

Most reverse implications are false. Two simple examples illustrate why.

2.1.6 Counterexamples: Why the notions of convergence matter

The implications between the different types of convergence generally cannot be reversed. Two examples illustrate why.

2.1.6.1 Counterexample 1: Convergence in probability does not imply convergence in mean square

Consider the random variables

\[ Y_n = \begin{cases} n, & \text{with probability }1/n^2,\\ 0, & \text{otherwise}. \end{cases} \]

For every fixed \(\varepsilon>0\) and sufficiently large \(n\),

\[ \mathbb P(|Y_n|>\varepsilon)=\frac{1}{n^2}\longrightarrow 0. \]

Thus, \(Y_n\xrightarrow{P}0\). However,

\[ \mathbb E[Y_n^2]=n^2\cdot\frac{1}{n^2}=1 \]

for every \(n\), so \(Y_n\) does not converge in mean square to zero.

Intuition: Very large values become increasingly rare, but their squared magnitude grows fast enough to keep the expected squared error constant.

fig, axes = plt.subplots(1, 3, figsize=(9, 3.2))

for ax, n in zip(axes, [2, 5, 10]):
    probabilities = [1 - 1/n**2, 1/n**2]
    ax.bar([0, 1], probabilities, color=["steelblue", "darkorange"])
    ax.set_xticks([0, 1], ["0", str(n)])
    ax.set_ylim(0, 1.05)
    ax.set_title(f"n = {n}")
    ax.set_xlabel("Value of $Y_n$")
    ax.text(1, probabilities[1] + 0.04,
            f"{1/n**2:.2%}", ha="center", fontsize=9)

axes[0].set_ylabel("Probability")
fig.tight_layout()
plt.show()

2.1.6.2 Counterexample 2: Convergence in probability does not imply almost sure convergence

Consider the sample space \(\Omega=[0,1)\) with the uniform distribution. We construct a sequence of random variables that equal \(1\) on a small interval and \(0\) elsewhere.

First, we select the entire interval \([0,1)\). Next, we select its two halves in turn, then its four quarters, then its eight eighths, and so on.

More precisely, for \(n=2^k+j\), with \(k\geq 0\) and \(j=0,\ldots,2^k-1\), define

\[ Y_n(\omega)= \begin{cases} 1, & \displaystyle \omega\in \left[\frac{j}{2^k},\frac{j+1}{2^k}\right),\\[6pt] 0, & \text{otherwise}. \end{cases} \]

The following diagram illustrates this construction. Each colored interval represents the set of outcomes for which \(Y_n=1\).

fig, ax = plt.subplots(figsize=(9, 4.5))

omega = 0.3
rows = []

for k in range(4):
    for j in range(2**k):
        rows.append((k, j, j / 2**k, (j+1) / 2**k))

for i, (k, j, left, right) in enumerate(rows):
    ax.barh(i, right-left, left=left, height=0.75,
            color="steelblue", edgecolor="white")

ax.axvline(omega, color="darkorange", ls="--", lw=2,
           label=rf"Fixed outcome $\omega={omega}$")

ax.set_xlim(0, 1)
ax.set_ylim(len(rows)-0.2, -0.8)
ax.set_xlabel(r"Outcome $\omega\in[0,1)$")
ax.set_ylabel("Random variable $Y_n$")

ax.set_yticks(range(len(rows)))
ax.set_yticklabels([f"$Y_{{{i+1}}}$" for i in range(len(rows))])

ax.legend(loc="lower right")
fig.tight_layout()
plt.show()

Convergence in probability: At stage \(k\), the interval where \(Y_n=1\) has length \(2^{-k}\). Hence,

\[ \mathbb P(Y_n=1)=2^{-k}\longrightarrow 0 \]

as \(n\to\infty\). Therefore, \(Y_n\xrightarrow{P}0\).

Almost sure convergence: Fix any \(\omega\in[0,1)\). At every stage \(k\), exactly one of the intervals contains \(\omega\). Thus, \(Y_n(\omega)=1\) infinitely often. It also equals \(0\) infinitely often.

Consequently, \(Y_n(\omega)\) does not converge for any \(\omega\in[0,1)\), and almost sure convergence fails.

Intuition: The interval where \(Y_n=1\) becomes smaller and smaller, but keeps moving across the sample space. Deviations become increasingly unlikely at each step, yet every individual outcome is hit infinitely often.

ImportantKey takeaway
  • Convergence in probability: The probability of a substantial deviation becomes arbitrarily small.
  • Almost sure convergence: Along almost every individual sequence of outcomes, substantial deviations eventually stop occurring.
  • Convergence in mean square: The expected squared error becomes arbitrarily small.

These requirements are different, and convergence in probability alone does not guarantee either of the other two.

2.2 Law of large numbers

The law of large numbers (LLN) formalizes a fundamental idea in statistics: averages of repeated random observations approach their theoretical expectations as the sample size increases.

Let \(X_1,X_2,\ldots\) be i.i.d. observations with \(\mathbb E[|X_1|]<\infty\) and mean \(\mu=\mathbb E[X_1]\). The weak law of large numbers states that

\[ \boxed{ \overline X_n=\frac1n\sum_{i=1}^n X_i \xrightarrow{P}\mu. } \]

Thus, for every \(\varepsilon>0\),

\[ \mathbb P(|\overline X_n-\mu|\geq\varepsilon) \longrightarrow 0. \]

The strong LLN establishes the stronger result \(\overline X_n\xrightarrow{a.s.}\mu\): along almost every infinite sequence of observations, the sample average approaches \(\mu\).

If \(\operatorname{Var}(X_i)=\sigma^2<\infty\), we have seen, that the empirical mean converges in mean square by Markov’s, which is implies the weak law of large numbers. Precisely, we have seen that: \[ \mathbb P(|\overline X_n-\mu|\geq\varepsilon) \leq \frac{\sigma^2}{n\varepsilon^2} \longrightarrow 0. \] This establishes convergence, although the bound may be much larger than the actual deviation probability.

2.2.1 Frequentist interpretation: probabilities and moments

The LLN connects theoretical properties of a distribution to observable quantities in repeated experiments.

Indeed, we can apply it to any function \(g(X)\) with finite absolute expectation:

\[ \boxed{ \frac1n\sum_{i=1}^n g(X_i) \xrightarrow{a.s.}\mathbb E[g(X)]. } \]

Two important applications are:

  • Probabilities: For \(g(X)=\mathbf 1\{X\in A\}\), the observed relative frequency of an event approaches its probability \(\mathbb P(X\in A)\).
  • Moments: For \(g(X)=X^k\), the empirical moment \(n^{-1}\sum_i X_i^k\) approaches the theoretical moment \(\mathbb E[X^k]\), provided \(\mathbb E[|X|^k]<\infty\).

This provides the frequentist interpretation of probabilities and moments discussed earlier.

Consider \(X_i\sim\mathrm{Exponential}(1)\). We know that

\[ \mathbb P(X_i\leq 1)=1-e^{-1}, \qquad \mathbb E[X_i^k]=k!. \]

We compare empirical event frequencies with empirical moments as the sample size increases.

from math import factorial

rng_lln = np.random.default_rng(2026)
N = 30_000
n = np.arange(1, N + 1)
samples = rng_lln.exponential(size=(3, N))

fig, axes = plt.subplots(1, 2, figsize=(10, 3.8))

# Event probabilities: three independent sample paths
p = 1 - np.exp(-1)

for x in samples:
    freq = np.cumsum(x <= 1) / n
    axes[0].plot(n, freq, lw=1, alpha=0.8)

axes[0].axhline(p, color="black", ls="--", label=r"$P(X\leq 1)$")
axes[0].set_title("Relative frequency")
axes[0].set_ylabel(r"Fraction with $X_i\leq 1$")
axes[0].legend()

# Empirical moments: same observations, different powers
x = samples[0]

for k in [1, 2, 4]:
    empirical = np.cumsum(x**k) / n
    axes[1].plot(n, empirical / factorial(k), lw=1,
                 label=fr"$k={k}$")

axes[1].axhline(1, color="black", ls="--")
axes[1].set_title("Empirical moments")
axes[1].set_ylabel("Empirical / theoretical moment")
axes[1].legend()

for ax in axes:
    ax.set_xscale("log")
    ax.set_xlim(100, N)
    ax.set_xlabel("Sample size $n$")

fig.tight_layout()
plt.show()

What do we observe?

Both relative frequencies and empirical moments approach their theoretical values. However, higher empirical moments fluctuate more strongly and may require considerably larger samples to become precise.

The reason is their variance. If \(\mathbb E[X^{2k}]<\infty\),

\[ \operatorname{Var}\left( \frac1n\sum_{i=1}^n X_i^k \right) = \frac{\operatorname{Var}(X^k)}{n}. \]

For our Exponential(1) example,

\[ \operatorname{Var}(X^k)=(2k)!-(k!)^2. \]

Consequently, the relative standard errors of the first, second, and fourth empirical moments are

\[ \frac{1}{\sqrt n},\qquad \frac{\sqrt 5}{\sqrt n},\qquad \frac{\sqrt{69}}{\sqrt n}, \]

respectively.

All three estimators converge, but the higher moments are much less precise for a given sample size.

Consequently, the LLN tells us that empirical averages converge to their theoretical expectations. Markov’s inequality provides an upper bound on their deviation probabilities. But neither tells us precisely how likely a given estimation error is in a finite sample.

To understand the distribution of these errors, rather than merely bound their probabilities, we turn to the central limit theorem.

2.3 Central limit theorem

The LLN establishes that empirical averages converge to their theoretical expectations. But how precise is an empirical average for a given sample size? Markov’s inequality provides an upper bound on the probability of an estimation error, but this bound can be very conservative. The central limit theorem (CLT) provides a more informative answer by approximating the sampling distribution of empirical averages.

For i.i.d. observations with \(\mathbb E[X_i]=\mu\) and \(0<\operatorname{Var}(X_i)=\sigma^2<\infty\), \[ \boxed{ \frac{\sqrt n(\overline X_n-\mu)}{\sigma} \xrightarrow{d}N(0,1). } \]

Recall that convergence in distribution means that the CDFs converge at every continuity point of the limiting CDF. Thus, for sufficiently large \(n\), the sample mean is approximately Normally distributed: \[ \overline X_n\ \overset{\text{approx.}}\sim\ N\left(\mu,\frac{\sigma^2}{n}\right). \] The LLN tells us where the sample mean concentrates. The CLT describes the distribution of its fluctuations around the population mean.

Let \(\Phi\) denote the CDF of the standard Normal distribution. The CLT suggests that, for sufficiently large \(n\), \[ \mathbb P\left( |\overline X_n-\mu|\geq z\frac{\sigma}{\sqrt n} \right) \approx 2[1-\Phi(z)]. \] For example, consider deviations larger than two standard errors:

  • Markov’s inequality: The probability is at most \(1/4=25\%\).

  • CLT approximation: The probability is approximately \(4.6\%\).

Unlike Markov’s inequality, the CLT provides an approximation rather than a guaranteed bound. Its accuracy depends on the population distribution and the sample size.

2.3.1 Frequentist interpretation: Centered Moments as uncertainty indicators

As with the LLN, we can apply the CLT to any transformation \(g(X)\) with finite, positive variance: \[ \frac{ \sqrt n\left( \frac1n\sum_{i=1}^n g(X_i)-\mathbb E[g(X)] \right) }{ \sqrt{\operatorname{Var}(g(X))} } \xrightarrow{d}N(0,1). \]

In particular, choosing \(g(X)=X^k\) gives a Normal approximation for empirical moments, provided \(\mathbb E[X^{2k}]<\infty\).

Recall our Exponential(1) example:

\[ \mathbb E[X^k]=k!, \qquad \operatorname{Var}(X^k)=(2k)!-(k!)^2. \]

Higher empirical moments have much larger relative standard errors. Moreover, the distributions of \(X^k\) become increasingly skewed, so their Normal approximations may require much larger sample sizes to become accurate.

We return to \(X_i\sim\mathrm{Exponential}(1)\) and simulate many independent samples. We compare the standardized empirical mean and fourth empirical moment with the standard Normal density.

3 Conditional Probability and Conditional Expectation

In many statistical applications, we want to make predictions about a random variable \(Y\) based on information about another random variable \(X\) For example, we might want to predict a person’s income from their education, or the probability of developing a disease from age and other characteristics.

The mathematical concepts underlying these questions are conditional probability and conditional expectation.

3.1 Discrete Case

If \(X\) and \(Y\) are discrete random variables such that \(\mathbb P[X>0]=1\) . We write \[ \begin{aligned} \mathbb P[Y=y\mid X=x] = & \frac{\mathbb P[Y=y,X=x]}{\mathbb P[X=x]},\\ \mathbb E[Y\mid X=x] = & \sum_y y\,\mathbb P[Y=y\mid X=x], \end{aligned} \] for conditional probabilities and conditional expectations, provided \(\mathbb P[X=x]>0\), assuming the sum is absolutely convergent.

In particular, for each possible value \(x\), we obtain a number \[ m(x)=\mathbb E[Y\mid X=x]. \] The function \(m\) is called the conditional expectation function or regression function.

The random variable \(m(X)\) is denoted by \(\mathbb E[Y\mid X]\).

NoteExample: Two dice

We roll two independent fair dice. Let \(X\) denote the result of the first die and \(Y\) the sum of both dice.

Then

\[ \mathbb E[Y\mid X=x]=x+3.5. \]

Hence, knowing the outcome of the first die changes our expected value of the sum.

TipExercise

Show that if \(X\) and \(Y\) are independent, then

\[ \mathbb E[Y\mid X]=\mathbb E[Y]. \]

The conditional expectation has a particularly useful property: it is the best predictor of \(Y\) based on \(X\) when prediction errors are measured by mean squared error.

To see this, first observe that \[ \begin{aligned} \sum_y \mathbb P[Y=y|X=x]= & \frac{\sum_y \mathbb P[Y=y,X=x]}{ \mathbb P[X=x]}\\ = & \frac{ \mathbb P[\bigcup_y {Y=y,X=x}]}{ \mathbb P[X=x]}\\ = & \frac{ \mathbb P[X=x]}{ \mathbb P[X=x]}=1 \end{aligned} \] Then, for any function \(g\), assuming finite second moments, we obtai by linearity of the expectation that \[ \begin{aligned} \mathbb E[(Y-g(X))^2] = &\mathbb E[(Y-m(X)+m(x)-g(x))^2]\\ = & \mathbb E[(Y-m(X))^2]+2\mathbb E[(Y-m(X)m(X)-g(X))^2]\\ &+\mathbb E[(m(X)-g(X))^2]\\ = &\mathbb E[(Y-m(X))^2] \\ &+ \sum_x (m(x)-g(x)) \underbrace{\sum_y (y-m(x)) \mathbb P[Y=y|X=x]}_{=\sum_y y\mathbb P[Y=y|X=x]-m(x)\sum_y \mathbb P[Y=y|X=x] =0}\mathbb P[X=x]\\ & + \sum_x(m(x)-g(x))^2 \underbrace{\sum_y \mathbb P[Y=y|X=x]}_{=1}\mathbb P[X=x]\\ \geq & \mathbb E[(Y-m(X))^2. \end{aligned} \] Hence, \[ \boxed{ \mathbb E[(Y-g(X))^2] \geq \mathbb E[(Y-m(X))^2]. } \]

Thus, \(m(X)\) minimizes the mean squared prediction error among all square-integrable functions of \(X\).

3.2 General case

In regression, we often want to calculate expressions such as \[ \mathbb E[Y\mid X=x], \] where \(X\) has a density. But then \(\mathbb P[X=x]=0\) for every \(x\). Consequently, the definition based on dividing by \(\mathbb P[X=x]\) does not work.

How can we define conditional expectations in this situation?

The answer is surprisingly simple: We can directly define the conditional expectation function \(m\) as the function that optimally predicts \(Y\) from \(X\) in mean square. That is, if \(\mathbb E[Y^2]<\infty\), the conditional expectation \(m(X)=\mathbb E[Y\mid X]\) satisfies \[ \boxed{ m\in\underset{g}{\operatorname{argmin}}\; \mathbb E[(Y-g(X))^2]. } \]

Note
  • the minimum is not taken over all functions \(g\), but over all functions, for which the expectation \(E[(Y-g(X))^2]\) is well-defined. This class is very large and the corresponding functions are called measurable functions.
  • Strictly, the minimizing random variable \(m(X)\) is unique up to almost-sure equality. Accordingly, \(m(x)\) is determined only for \(P_X\)-almost every \(x\).
Tip

There are other, equivalent characterizations of conditional expectation. For instance, when a conditional density exists, \[ \mathbb E[Y\mid X=x] = \int_{-\infty}^{\infty} y f_{Y\mid X}(y\mid x)\,dy. \] See Wasserman (2004), All of Statistics, Section 3.5, for conditional expectations defined through conditional distributions.

The least-squares characterization is particularly useful for regression because it does not require us to calculate conditional densities explicitly.

We may also define more general conditional moments. Of particular importance is the conditional variance which describes the remaining variability of \(Y\) when \(X\) is known, that is, for a square-integrable random variable \(Y\), the conditional variance of \(Y\) given \(X\) is \[ \operatorname{Var}(Y\mid X) = \mathbb E\left[ (Y-\mathbb E[Y\mid X])^2\mid X \right]. \] Equivalently, \[ \operatorname{Var}(Y\mid X) = \mathbb E[Y^2\mid X] - (\mathbb E[Y\mid X])^2. \]

3.2.1 Properties of conditional expectation and variance

Conditional Expectations have many desirable properties.

NoteLemma: Properties of conditional expectations

Let \(X\) and \(Y\) be random variables with \(\mathbb E[Y^2]<\infty\), and write \(m(X)=\mathbb E[Y\mid X]\).

The following properties hold:

  1. Centered residuals and orthogonality:

    \[ \mathbb E[Y-m(X)\mid X]=0, \]

    and, for every square-integrable function \(h(X)\),

    \[ \mathbb E[(Y-m(X))h(X)]=0. \]

  2. Linearity: For square-integrable random variables \(Y,Z\),

    \[ \mathbb E[aY+bZ\mid X] =a\mathbb E[Y\mid X]+b\mathbb E[Z\mid X]. \]

  3. Taking out what is known: For a bounded measurable function \(h\),

    \[ \mathbb E[h(X)Y\mid X] =h(X)\mathbb E[Y\mid X]. \]

    In particular,

    \[ \mathbb E[h(X)\mid X]=h(X). \]

  4. Law of iterated expectations (tower property):

    \[ \mathbb E[\mathbb E[Y\mid X]]=\mathbb E[Y]. \]

  5. Law of total variance:

    \[ \operatorname{Var}(Y) = \mathbb E[\operatorname{Var}(Y\mid X)] + \operatorname{Var}(\mathbb E[Y\mid X]), \]

    where

    \[ \operatorname{Var}(Y\mid X) = \mathbb E[(Y-m(X))^2\mid X]. \]

All equalities between conditional expectations hold almost surely.

Proof. We use the characterization of conditional expectation as the minimizer of mean squared prediction error.

1. Orthogonality. Since \(m(X)\) minimizes \(\mathbb E[(Y-g(X))^2]\), for every square-integrable \(h(X)\), the function

\[ q(t)=\mathbb E[(Y-m(X)-th(X))^2] \]

is minimized at \(t=0\). Differentiating gives

\[ q'(0)=-2\mathbb E[(Y-m(X))h(X)]=0. \]

Thus,

\[ \mathbb E[(Y-m(X))h(X)]=0. \]

In particular, the conditional expectation of the residual \(Y-m(X)\) is zero, since the zero function is its best mean squared predictor based on \(X\).

2. Linearity. Write \(m_Y(X)=\mathbb E[Y\mid X]\) and \(m_Z(X)=\mathbb E[Z\mid X]\). For every square-integrable \(h(X)\),

\[ \begin{aligned} &\mathbb E[(aY+bZ-am_Y(X)-bm_Z(X))h(X)]\\ &=a\mathbb E[(Y-m_Y(X))h(X)]\\ &\quad+b\mathbb E[(Z-m_Z(X))h(X)]=0. \end{aligned} \]

Hence \(am_Y(X)+bm_Z(X)\) is the best mean squared predictor of \(aY+bZ\) based on \(X\).

3. Taking out what is known. For bounded \(h(X)\) and every square-integrable function \(g(X)\),

\[ \begin{aligned} &\mathbb E[(h(X)Y-h(X)m(X))g(X)]\\ &=\mathbb E[(Y-m(X))h(X)g(X)]=0. \end{aligned} \]

Thus \(h(X)m(X)\) is the best mean squared predictor of \(h(X)Y\). Moreover, if \(Y=h(X)\), then \(Y\) can be predicted perfectly from \(X\), so \(\mathbb E[h(X)\mid X]=h(X)\) (for any square-integrable \(h(X)\)).

4. Law of iterated expectations. Choosing \(h(X)=1\) in the orthogonality property gives

\[ \mathbb E[Y-m(X)]=0, \]

which proves the claim.

5. Law of total variance. Write

\[ Y-\mathbb E[Y] = (Y-m(X))+(m(X)-\mathbb E[Y]). \]

Squaring and taking expectations, the cross term vanishes by orthogonality. Hence

\[ \begin{aligned} \operatorname{Var}(Y) &=\mathbb E[(Y-m(X))^2]\\ &\quad+\mathbb E[(m(X)-\mathbb E[Y])^2]\\ &=\mathbb E[\operatorname{Var}(Y\mid X)] +\operatorname{Var}(m(X)), \end{aligned} \]

where the final equality uses the law of iterated expectations. \(\square\)

3.2.2 Conditional Probabilities in the continuous case

We may also define conditional probabilities in the context of continuous random variables via conditional expectations. For an event \(A\), let \[ \mathbf 1_A(\omega):= \begin{cases} 1 & \text{if } \omega \in A\\ 0 & \text{otherwise} \end{cases} \] be its indicator variable. Then \[ \boxed{ \mathbb P[A\mid X] = \mathbb E[\mathbf 1_A\mid X]. } \]

3.3 Frequentist interpretation: Prediction and mean squared error

We have seen that the conditional expectation

\[ m(X)=\mathbb E[Y\mid X] \]

is the best predictor of \(Y\) based on \(X\) when prediction errors are measured by mean squared error.

However, in statistics, we often restrict ourselves to a particular class of prediction functions.

For example, the best linear predictor (allowing an intercept) is defined by

\[ \boxed{ g^*_{\mathrm{lin}} \in \underset{g(x)=a+bx}{\operatorname{argmin}} \mathbb E[(Y-g(X))^2]. } \]

The conditional expectation, in contrast, minimizes the population mean squared error over all square-integrable functions of \(X\):

\[ \boxed{ m \in \underset{g}{\operatorname{argmin}} \mathbb E[(Y-g(X))^2]. } \]

Consequently,

\[ \mathbb E[(Y-m(X))^2] \leq \mathbb E[(Y-g^*_{\mathrm{lin}}(X))^2]. \]

The inequality may be strict: Even the best linear predictor can be substantially worse than the conditional expectation if the relationship between \(X\) and \(Y\) is nonlinear.

3.3.1 Example: Best linear predictor vs. conditional expectation

Consider

\[ X\sim N(0,1),\qquad Y=X^2+\varepsilon, \qquad \varepsilon\sim N(0,1), \]

where \(X\) and \(\varepsilon\) are independent.

The conditional expectation is

\[ m(x)=\mathbb E[Y\mid X=x]=x^2. \]

Recall that the population-optimal affine predictor is

\[ g^*_{\mathrm{lin}}(x) = \mathbb E[Y] + \frac{\operatorname{Cov}(X,Y)}{\operatorname{Var}(X)} (x-\mathbb E[X]). \]

Since

\[ \mathbb E[Y]=1,\qquad \operatorname{Cov}(X,Y)=0, \]

we obtain

\[ \boxed{g^*_{\mathrm{lin}}(x)=1.} \]

Thus, even the best affine predictor does not capture the nonlinear relationship.

The population prediction errors are

\[ \begin{aligned} R(g^*_{\mathrm{lin}}) &=\mathbb E[(Y-1)^2]=3,\\ R(m) &=\mathbb E[(Y-X^2)^2]=1. \end{aligned} \]

We visualize the observations and both population-optimal prediction functions.

3.4 Frequentist interpretation: Conditional expectation and prediction

We have seen that the conditional expectation \[ m(x)=\mathbb E[Y\mid X=x] \] minimizes the population mean squared prediction error \[ R(g)=\mathbb E[(Y-g(X))^2]. \] But what does this mean in terms of observable prediction errors?

Suppose we observe a random sample \[ (X_1,Y_1),\ldots,(X_n,Y_n). \] Since we cannot directly observe the population expectation, we might try to replace it by an empirical average: \[ \widehat R_n(g) = \frac1n\sum_{i=1}^n(Y_i-g(X_i))^2. \] It seems natural to find the prediction function that minimizes this empirical criterion: \[ \widehat g \in \underset{g}{\operatorname{argmin}}\; \widehat R_n(g). \]

But there is a problem. If we allow arbitrary prediction functions and the observed covariate values are distinct, we can always construct a function satisfying \[ \widehat g(X_i)=Y_i \qquad\text{for all }i=1,\ldots,n. \] Such a function interpolates all observations and therefore achieves \[ \boxed{\widehat R_n(\widehat g)=0.} \] Does this mean we have found a perfect predictor? No. The function may simply reproduce the observed data without predicting new observations accurately. This phenomenon is called overfitting.

Consider again \[ X\sim N(0,1),\qquad Y=X^2+\varepsilon,\qquad \varepsilon\sim N(0,1), \] where \(X\) and \(\varepsilon\) are independent. The conditional expectation is \[ m(x)=x^2, \] with population mean squared prediction error \[ R(m)=\mathbb E[\varepsilon^2]=1. \] The best affine predictor is the constant function \[ g^*_{\mathrm{lin}}(x)=1, \] with population mean squared prediction error \[ R(g^*_{\mathrm{lin}})=3. \]

We now construct a third predictor by connecting the observed data points with straight lines. This interpolating function achieves zero empirical prediction error on the original observations. But what happens when we use these prediction functions on new, independently generated observations?

To understand the predictive interpretation of conditional expectation, consider the following random experiment for a fixed prediction function \(g\):

  1. Draw a new pair \((X,Y)\) from the population.
  2. Predict \(Y\) using \(g(X)\).
  3. Calculate the squared prediction error \((Y-g(X))^2\).

We repeat this experiment independently \(N\) times, keeping the prediction function \(g\) unchanged.

The average squared prediction error is

\[ \widehat R_N(g) = \frac1N\sum_{i=1}^N(Y_i-g(X_i))^2. \]

By the strong law of large numbers, for every fixed \(g\) with finite mean squared prediction error,

\[ \boxed{ \widehat R_N(g) \xrightarrow{a.s.} \mathbb E[(Y-g(X))^2]. } \]

Thus, the expected squared prediction error is the long-run average squared prediction error when we repeatedly use the same function to predict new observations.

Recall that we have already established that the conditional expectation

\[ m(x)=\mathbb E[Y\mid X=x] \]

minimizes the population mean squared prediction error over all admissible prediction functions.

The law of large numbers therefore provides the following frequentist interpretation: The conditional expectation is the prediction function that minimizes the long-run average squared prediction error when predicting new independent observations.

ImportantFrequentist interpretation of conditional expectation

Importantly, this does not mean that it minimizes the prediction error on every particular sample. A function may achieve zero error on the observations used to construct it, while performing poorly on new observations. This is the problem of overfitting.
